# Rada Constructions -- Portfolio Showcase

A web-based, interactive portfolio component built for **Rada
Constructions**, an architectural, interior design, and engineering firm
based in Jabalpur, Madhya Pradesh.

Founded in 1989, the firm was established with a vision to improve
quality of life and turn dreams into reality. This project features a
modern, interactive image carousel that showcases the company's
commercial projects, residential townships, and interior visualizations.

## 💻 Technical Overview

This repository contains the front-end source code for the interactive
gallery slider.

## 🛠️ Tech Stack

-   **HTML5:** Provides the semantic layout and structure.
-   **CSS3:** Custom styling featuring the Poppins font, clean card
    layouts, and responsive design.
-   **JavaScript:** Handles integration and initialization logic.
-   **Swiper.js:** A modern, touch-enabled slider library that provides
    smooth image transitions, pagination, and navigation.

## 🚀 Local Setup

Follow these steps to run the project locally:

1.  **Clone or download** this repository to your computer.
2.  Ensure the `images/` folder contains your project photos (for
    example, `1.jpg`, `2.jpg`, and so on) and that the folder is located
    in the same directory as the project code.
3.  Open `index.html` in your default web browser by double-clicking it.

No local server setup is required for the basic project.
