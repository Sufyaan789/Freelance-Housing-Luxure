Rada Constructions - Portfolio Showcase

A web-based interactive portfolio component built for Rada Constructions, a premier architectural, interior design, and engineering firm based in Jabalpur, Madhya Pradesh.

Founded in 1989, the driving force behind the establishment of the firm was to improve the quality of life and turn dreams into reality. This project features a modern, interactive image carousel designed to beautifully showcase the company's notable commercial projects, residential townships, and interior visualizations.

🏢 About the Leadership

Er. Masood Ahmed (Founder): A vastly experienced Civil Engineer who believes in building strong foundations—both in construction and client relationships. He has been conferred with prestigious awards including the Glory of India Award (2016) and Bharat Jyoti Award (2017) for his remarkable contributions to national development.

The Associates: A perfect blend of engineering and art, supported by Ar. Arshad Rada and Er. Faizan Rada.

💻 Technical Overview

This repository contains the front-end source code for the interactive gallery slider.

🛠️ Tech Stack

HTML5: Semantic layout and structure.

CSS3: Custom styling featuring the 'Poppins' font, clean card layouts, and responsive design.

JavaScript: Integration and initialization logic.

Swiper.js: A modern, touch-enabled slider library used for smooth image transitions, pagination, and navigation.

🚀 Local Setup

To run this project locally on your machine:

Clone this repository to your local computer.

Ensure you have the images/ folder populated with your project photos (1.jpg, 2.jpg, etc.) in the same directory as your code.

Simply double-click the index.html file to open it in your default web browser. No server setup is required!
